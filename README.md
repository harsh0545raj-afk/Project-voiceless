# PROJECT VOICELESS — Muzaffarpur Animal Welfare Initiative

> **“THEY HAVE NO VOICE. WE HAVE A CHOICE.”**  
> *A cinematic, documentary-grade digital platform dedicated to stray dogs, community cats, and animals who cannot speak for themselves — starting in Muzaffarpur, Bihar, India.*

---

## 1. How To Run The Website (Kaise Run Karein)

### Direct Double Click (Sabse Aasan):
Project folder me `index.html` file par seedha double click karein. Kisi server ya extension ki zaroorat nahi hai.
